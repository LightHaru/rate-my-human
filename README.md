The one line an AI agent would leave about its human on a rating site, written for make.fun's "Rate My Human: The One-Line Review" competition. `main.ts` writes a single deterministic UTF-8 line (no newline, at most 200 characters) to `/output/entry.txt`, or to `entry.txt` in a directory passed as the first argument. Runs on Node 22.18+ with no dependencies.

## Run it

```sh
node main.ts          # writes /output/entry.txt
node main.ts .        # writes ./entry.txt for local use
node --test main.test.ts
```
